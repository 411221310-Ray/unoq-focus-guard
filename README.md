# FocusGuard — UNO Q 在座偵測專注番茄鐘

AIoT 期中專題。用筆電鏡頭把畫面經 USB 送到 Arduino UNO Q，板子在本機跑人臉偵測，
判斷「人是否在座位上」，自動控制番茄鐘，並把狀態顯示在板上的 LED 矩陣與網頁儀表板。

> 繳交期限：**11/19（四）中午 12:00**，不收遲交。

## 為什麼選這個題目

- **不用買硬體**：只需要 UNO Q + 筆電 + USB 線，跟課堂 w06 的環境一樣。
- **風險低**：影像管線（筆電鏡頭 → USB → 板上人臉偵測 → WebUI）課堂上已經跑通，專題是在上面加自己的邏輯。
- **看得出是 AIoT**：Linux 端（MPU）做 AI 推論，MCU 端即時驅動 LED 矩陣，兩邊用 Bridge 溝通。
- **全部在板子本機跑**：不接雲端 API，天生沒有金鑰/密碼外洩的問題。
- **影片好拍**：人離開座位 → 計時暫停、LED 變警示；人回來 → 繼續，一看就懂。

## 系統架構

```
筆電鏡頭 ──JPEG/WebSocket(USB)──▶ UNO Q Linux 端 (Python)
                                   ├─ VideoObjectDetection (face-detection)
                                   ├─ 狀態機：專注 / 暫離 / 休息
                                   ├─ 番茄鐘計時 + 統計紀錄
                                   ├─ WebUI ──▶ 瀏覽器儀表板
                                   └─ Bridge ──▶ MCU (sketch)
                                                  └─ 8x13 LED 矩陣顯示
```

## 功能分級

### 必做（MVP，先做完這些就能交）

1. 在座偵測：連續 N 秒偵測不到人臉 → 判定「暫離」；重新偵測到 → 回到「專注」（要做防抖，避免低頭一下就誤判）。
2. 番茄鐘：專注 25 分鐘 / 休息 5 分鐘（示範時可調成 1 分鐘 / 20 秒）；暫離時計時自動暫停。
3. LED 矩陣：專注中顯示剩餘時間進度條；暫離時閃爍警示圖案；休息時顯示笑臉。
4. 網頁儀表板：目前狀態、倒數時間、今日專注總時間、暫離次數。

### 加分（有時間再做，依序）

1. 專注紀錄時間軸（每段專注/暫離畫成色條）。
2. 偵測到兩張以上人臉 → 記一次「被打擾」。
3. 紀錄存成 CSV，重開 App 後還能看歷史。
4. 換用一般物件偵測模型，偵測畫面中出現手機 → 記一次「分心」。

## 怎麼跑

和課堂 w06 的流程一樣，只是把 App 換成 `app/`：

1. 筆電用 USB-C 線接上 UNO Q，照課堂步驟跑 `w06-starter/pc` 的 USB 通道腳本。
2. 把 `app/` 整個資料夾放進 App Lab（或複製到板子上的 App 目錄），按 Run。App Lab 會同時燒錄 `sketch/` 到 MCU、啟動 `python/main.py`。
3. 打開網頁，先在「1. 選擇攝影機」按 **開始辨識**，再按上方的 **開始專注**。
4. 示範模式預設打開（專注 1 分鐘／休息 20 秒）；取消勾選就是正式的 25／5 分鐘。

### 程式檔案

| 檔案 | 內容 |
|---|---|
| `app/python/main.py` | 偵測回呼、防抖、番茄鐘狀態機，每 0.25 秒推狀態給網頁、送畫面給 LED 矩陣 |
| `app/python/led_frames.py` | LED 矩陣的畫面（進度條、警示、笑臉、慶祝動畫）；`python led_frames.py` 可在電腦上預覽 |
| `app/sketch/sketch.ino` | MCU 端：提供 Bridge `draw`，把 104 格亮度畫到矩陣上 |
| `app/assets/pomodoro.js` | 網頁儀表板：大字倒數、統計、按鈕、Web Audio 提示音 |
| `app/assets/app.js` | 課堂 starter 原本的送畫面程式（沒改） |

### 可調參數（`app/python/main.py` 最上面）

- `AWAY_GRACE_SEC = 3.0`：連續幾秒沒看到人才判定暫離。常誤判就調大。
- `DETECT_LABEL = "face"`：換成有 person 類別的模型時改成 `"person"`。
- `MIN_BOX_RATIO = 0.0`：框太小（人離鏡頭很遠）就不算在座；網頁「AI 偵測」卡片會顯示目前框大小，照著調。

## 待確認的風險

- **LED 矩陣與 Bridge 的寫法**：sketch 照 Arduino 官方範例（`02-led-matrix-frame`、`led-matrix-painter`）寫的，但還沒在這塊板子上跑過。MCU 沒回應時 Python 只會印一次警告，網頁和計時照常運作，退路是只用 WebUI 示範。
- **偵測穩定度**：側臉、低頭、光線差時可能誤判暫離，靠防抖秒數與信心門檻調整。
